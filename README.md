Welcome to the official repository for Opendroid Market Mobile, the dedicated Android mobile application experience for the Opendroid platform!

Historically, Opendroid operated as a web-based community marketplace and developer portal for Android applications (.apk files). Today, Opendroid Mobile brings the entire open-source repository directly to your mobile device. Browse, discover, download, install, and even manage app development on the go with zero proprietary bloat, telemetry, or restricted access.
